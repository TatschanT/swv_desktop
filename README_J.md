Standing Wave Viewer は、部屋の定在波（ルームモード）と低周波の干渉パターンを計算・可視化するための3D音響シミュレーションツールです。Pythonのフレームワークとして **PySide6 (Qt)** と **PyVista (VTK)** が用いられています. サブウーファーやスピーカーの最適な配置、およびリスニングポジションの決定に役立つでしょう。技術的な詳細については、/documents/Q_A_J.mdを参照してください。

このプロジェクトは、個人的な欲求から始まったアマチュアの試みであり、プロの現場で使われるような、厳密な検証ツールを目指したものではありません。
部屋のクセをできるだけ直感的に把握できるよう、自分用に作ったものです。
しかし、出来上がってみると、世の中にあまり類のないツールになったように感じたので、公開することにしました。
もしどこかの誰かの役に立てば、これ以上の喜びはありません。

## 主な機能
- **刷新されたUI**: すべての操作をシングルウィンドウで完結できるようにUIを刷新。3Dビュー、2Dのトップビュー、周波数グラフ、部屋のモード、コントロールバーが全て切り替えなしで表示されます。サイドバーのUIを使って、部屋の寸法、スピーカー座標、マイク座標、壁の反射率を直感的に調整できます。
- **周波数特性のシミュレーション**: 部屋の寸法と壁の反射率を考慮し、指定したマイク位置における周波数特性（20Hz〜250Hz, 変更可能）を計算します。
- **3Dボリュームレンダリング可視化**: 空間全体の音圧分布（波の「腹」と「節」）を3Dのボリュームデータとして描画し、周波数を変化させながらアニメーション再生が可能です。**NEW in V1.1** レンダリングモードを等高線モードにトグルで変更可能になりました。これにより見通しが必要な場合に対応できます。
- **計算モデルの選択**:
  モノラル、ステレオ（2音源）の設定に加えて、以下の3つの計算モデルを選択可能です：
  - **Uncorrelated (Independent Power Sum)**: ２つの音源から出た音波の間で干渉（打ち消し合い）を起こさず、単純なパワー加算を行います。部屋の素のモードを可視化するのに最適です。
  - **Global Cancel**: 高速に干渉を計算する近似モデルです。位相の違う波の間の干渉を全域でグローバルに計算します。音源がシンメトリー配置の場合に特に有効です。
  - **True Complex Field (Experimental)**: 空間の全座標で波を「複素数（実部＋虚部）」として合成し、非対称配置時に生じる「節の斜めの歪み」など、干渉を生々しく再現しようとする試みです。ただ、現実の空間においては、計算では起こりうるパーフェクトな干渉は知覚されません。様々な散乱要因が存在するからです。また、実際の音源は点音源ではないし、人間の知覚範囲も点ではありません。
- **Advanced Acoustics**
上記の、理想的な音響空間と現実世界の知覚とのギャップを埋めるために、「高度な音響設定」のスライダーを設置しました：
  - **Room Scatter (Order Damping)（高次モードの減衰）**：実際の部屋には、高周波の接線モードや斜めモードを散乱させる家具などがあります。このスライダーを使用して高次モードに $n^2$ の減衰係数を適用し、特定の空間の理想空間からの乖離度合いを微調整できます。一般的な生活空間においては、このスライダーを最大の0.5に設定した状態に近いと考えられます。
  - **Listening Area (Spatial Smoothing)（空間平滑化）**：私たちは小さな一点で音を聴いているわけではありません。このスライダーによりマイク周辺の圧力場を平均化する範囲を指定し、人間の知覚に合致するリアルな周波数特性を実現します。
- **データエクスポート**: 部屋の設定、周波数特性データ及びルームモードをCSVファイルとしてエクスポートできます。
- **Live Settings Tuning**: シミュレーションの精細度及び周波数領域を設定できます。変更はダイナミックに結果に反映されます。

## 🚀 3Dビューの操作
- **Contour mode**をオンにすると、音圧分布の表示が等高線モードに変化し、見通しが良くなります（が情報量は減ります）
- **Dynamic mode toggle**をオンにすると、音圧分布がすべてのパラメーター操作に追従します（要パワー）
- **Reset View**　カメラ位置が初期位置に戻ります。
- **NEW in v1.2.2** **Full-band Scaling**トグルをオンにするとレンダリングのスケールを全周波数範囲の分布に標準化します。トグルオンで簡易的にスケールを変化させますが、**Calibration**ボタンの押下より精密に全周波数範囲の音質分布を計算の上、中央値の-24dbから+15dbにスケールを校正します（数秒かかります）。
- **マウスの基本操作**
  - 左マウスクリックした状態でマウスを動かすとビューが回転します。
  - 右クリックした状態で上下にマウスを動かすと拡大縮小します。ホイール操作も拡大縮小です。
  - ホイールクリックでマウスを動かすと、ビューが水平移動します。Shiftを押しながらマウスを動かすのも同様です。
  - Cntlを押しながらマウスを動かすと、画面の中心に対して画面と水平面で回転させることが出来ます。

## 🛠️ インストールと実行方法

### Windows
Windows用のビルドは[Release](https://github.com/TatschanT/swv_desktop/releases/)からダウンロードしてください。任意のフォルダに解凍し、SWV.exeを実行してください。

### MacおよびLinuxのローカル環境での実行 
### 必要環境
- Python 3.10+ (Python 3.14/3.10はテスト済み)
- `PySide6`
- `pyvista`
- `pyvistaqt`
- `matplotlib` 
- `numpy`

### ローカル環境でのアプリの起動方法
1. リポジトリをクローンします
2. 仮想空間(`venv`)でのインストールと動作を推奨します
3. 必要環境のインストール:
   ```bash
   pip install PySide6 pyvista pyvistaqt matplotlib numpy
   ```
4. アプリを起動します:
   ```bash
   python main.py
   ```

**Linux / Wayland Note:** 
レンダリングに使用されているVTKの互換性制限のため、Wayland環境のLinux（Fedoraなど）では注意が必要です。現状はLinux環境においてはX11モードに強制する形でこの問題を回避しています(`QT_QPA_PLATFORM="xcb"`)ので、追加の対策は必要ありません。
